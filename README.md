# Weather Underground

Get the last data from you personal weather station and tomorrows forecast. Each is a separate "device" so you can add either or both as you desire.

In the weather station device's advanced settings, you can enable Approximate Luminance. It estimates outdoor lux by multiplying solar radiation (W/m²) by a configurable factor (default 126). This is not a direct light measurement; accuracy depends on the weather and sensor. Disabling it or losing the station's solar radiation reading removes the capability and may break Flows that use it.
